# 默默漫画视觉风格指南

## 角色设定

### 主人公：默默
- **外观**：短棕色头发的年轻女孩，绿色眼睛，穿着奶油色毛衣
- **性格特征**：温柔、善于观察、温暖
- **风格关键词**：柔和光线、温暖氛围、温柔表情、舒适室内场景

## 视觉风格

### 画风
- 现代动漫插画风格
- 柔和水彩质感
- 细腻的光影表现

### 色调
- 暖色调为主：大地色系、柔和粉彩
- 温柔的自然光照
- 避免高对比度和鲜艳色彩

### 情绪氛围
- 温馨、治愈、平和、亲密
- 日常生活中的小确幸
- 情感细腻的瞬间捕捉

### 构图原则
- 近景情感特写
- 日常生活场景
- 注重细节和氛围营造
- 第一人称视角或亲密观察视角

## 参考图使用说明

1. 将主角图 URL 填入 `character-config.json` 的 `character.protagonistImageUrl` 字段
2. 将场景/画风参考图 URL 填入 `character-config.json` 的 `character.referenceImageUrl` 字段
2. 参考图应清晰展示角色的主要特征（发型、服装、面部特征）
3. 图片生成时会自动以 Ark `image` 参数引用这些图片，保持角色形象和画风一致性

## Prompt 增强示例

生成的每个分镜 prompt 会自动添加：
- 角色描述前缀
- 风格关键词
- 氛围和色调约束

最终效果：保持主人公形象统一，画风一致，情感连贯。
